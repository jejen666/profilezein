Tentang Website

Website ini dibuat sebagai media pembelajaran dan memenuhi tugas mata kuliah Web Server dan Hosting.

Website ini dibangun menggunakan HTML, CSS, dan JavaScript, serta akan dihosting pada layanan hosting berbayar dengan domain sendiri.

Website ini juga telah dilengkapi dengan SSL (HTTPS) untuk keamanan data.

Tujuan Pembuatan Website

  • Memahami cara kerja web server dan hosting
  • Membuat website dengan domain sendiri
  • Mengaktifkan HTTPS / SSL Gratis
  • Membuat dan mengelola email domain
