Tentang Website

Website ini dibuat sebagai media pembelajaran sekaligus memenuhi tugas mata kuliah Web Server dan Hosting.

Website ini dibangun menggunakan teknologi HTML, CSS, dan JavaScript, kemudian dihosting menggunakan layanan hosting berbayar dengan domain sendiri agar dapat diakses secara online.

Selain itu website juga menggunakan HTTPS (SSL) sehingga komunikasi data antara pengguna dan server menjadi lebih aman.

Tujuan Pembuatan Website

  • Memahami konsep Web Server dan Hosting.
  • Mempelajari proses deploy website ke hosting.
  • Menggunakan domain sendiri.
  • Mengaktifkan HTTPS / SSL.
  • Mengelola email domain.
  • Membuat website yang responsif dan modern.
